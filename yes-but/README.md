# Да, но…

Весёлая игра для двоих или компании. Один телефон на всех: на экране мечта («Я умею летать»), один читает её вслух, другой отвечает «Но…» и портит всё как можно смешнее.

**[Играть](https://datakaterina.github.io/for_fun/yes-but/)**

Что умеет:
- 100 карточек, 8 категорий и общий Микс
- два режима: «Дуэль» (роли меняются, видно чья очередь) и «Компания» (телефон ходит по кругу)
- «Подсказка» с примером «Но…», спрятана, пока не нажмёшь
- «Пропустить» и «Назад» на предыдущую карточку
- необязательный таймер на 20 секунд, по умолчанию выключен
- карточки не повторяются, пока не пройдена вся колода
- без имён, очков и голосования
