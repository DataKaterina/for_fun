# for_fun

Небольшие игры и штуки для души. Каждая лежит в своей папке.

## Игры

### Где ты, шпион?

Игра на социальную дедукцию для компании от трёх человек. Один телефон ходит по кругу: все видят одно место, кроме шпиона. Нужно вычислить его по ответам на вопросы.

**[Играть](https://datakaterina.github.io/for_fun/gde-ty-shpion/)**

[Правила игры](https://datakaterina.github.io/for_fun/gde-ty-shpion/rules.html)

Что умеет:
- от 1 до 3 шпионов
- 126 мест, 10 тем, 3 уровня сложности
- режимы: шпион знает тему, шпионы знают друг друга
- необязательный таймер
- игра помнит выпавшие места и не повторяет их, пока не кончится весь список

Папка: [`gde-ty-shpion`](gde-ty-shpion)
